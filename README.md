# 👕 VesteBem

**Conectando solidariedade a benefícios reais para nossa cidade.

## 📌 Sobre o Projeto
O VesteBem é um aplicativo gamificado em Python projetado para resolver a falta de logística e incentivo nas doações de roupas locais. 
O sistema permite que usuários categorizem peças em casa, direcionem as doações para instituições parceiras da cidade (como APAE e Instituto São José) e acumulem pontos a cada doação validada. 

## ⚙️ Como Funciona
1. **Separe:** O doador realiza a triagem e cadastra os itens no app, organizando por categorias (Camisas, Calças, Sapatos, etc.).
2. **Doe:** Escolhe-se a instituição parceira ou o ponto de coleta mais próximo via geolocalização.
3. **Ganhe:** Após a instituição confirmar o recebimento, os pontos são creditados na carteira virtual do usuário para troca por prêmios.

## 🏆 Sistema de Benefícios
* **Semente (Até 100 pontos):** Cupons para sorteios na ACIAC.
* **Ramo (101 a 300 pontos):** Descontos exclusivos no comércio local parceiro.
* **Árvore (Acima de 300 pontos):** Percentual de desconto no carnê do IPTU.
* **Floresta (Top 10 do Ano):** Certificado Cidadão Solidário e prêmios especiais.
